The first release of Welp.

- Asks “Are you sure?” before you send a message to the WhatsApp chats you choose to protect.
- Three modes for each chat: ask before every message, ask before the first one, or hold the
  message a few seconds with Undo.
- A badge above the message box and a red menu bar shield while you are in a guarded chat.
- Welp Pro, a $9.99 yearly subscription, adds Slack, with Microsoft Teams and more to come.
- Welp keeps itself up to date, if you allow it.
