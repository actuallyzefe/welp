This update fixes ways a message could reach a protected chat without Welp asking first.

- Coming back to WhatsApp or Slack from another app no longer lets a message slip through
  while the app is still catching up. If Welp can't tell where Return goes, it asks.
- Photos and files you drop, attach or paste in WhatsApp now get the same question as
  messages, including in the chat with yourself. The badge shows above the caption box too.
- Welp keeps your Welp Pro license key if it can't save it, instead of forgetting it.
- If the Accessibility permission is missing, the settings window now says so, with a
  button to System Settings.
- The badge above the message box shows the whole mode name.
- The installer window shows Welp next to the Applications folder.
